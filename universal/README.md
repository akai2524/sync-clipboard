# 轻剪同步（非小米电脑）

这是给非小米 Windows 电脑使用的独立构建，与小米电脑版分开。新增自动选机、账号显示和传输状态的版本需要在新电脑上实际验证后才能确认正式发布。

## 当前验证范围

- 使用小米官方 Windows 通用版 1.1.2.36 安装包中签名有效的启动器和组件。自行编写的轻剪入口与安装程序不是小米官方文件；没有修改小米签名启动器。
- 已验证构建、安装包内容校验、小米签名宿主的自包含运行时启动自检和现有轻剪不受影响。自检不会登录小米账号、注册系统服务或启动互联组件。
- **用户已在非小米电脑反馈：旧版补注册官方服务并为手机实际 IPv4 地址配置入站规则后，电脑截图可以粘贴到手机；电脑到手机的文字和手机到电脑的图片也可同步。重启电脑后，旧版轻剪自动启动且截图仍可同步。**
- 用户确认在非小米电脑启用自动规则并临时停用原手机专属规则后，电脑截图可以粘贴到手机；重启后重复隔离测试仍成功，两次测试后原规则均已恢复。
- **用户清理旧版后，使用一体安装包在同一台非小米电脑安装，确认手机和电脑之间的文字、图片均可双向复制粘贴。** 换网、一体安装版重启后的表现，以及 Windows 10 和 11 分别兼容的情况仍需验证。
- 用户在另一台新电脑安装正式版候选包后，确认手机与电脑之间文字和图片均可双向同步；本次移除“待验证”文字后的构建仍需实际验证。
- 安装包约 219 MB，因为目前保留了官方账号、互联、服务修复组件及独立运行时。文件体积不代表内存占用；内存需要在目标电脑实测。为确保首次验证可用，目前没有把所有组件缩到最少。

## 测试方法

1. 将自动网络测试版安装包复制到非小米电脑，运行安装程序。推荐选择 `D:\Apps` 作为父目录，安装程序会创建 `D:\Apps\LightClipUniversal`。如果目标电脑没有 D 盘，选择其他仅包含英文、数字及常用符号的目录。
2. 安装程序自动检查并配置官方后台服务和网络规则，仅需按提示允许一次管理员授权，不需要单独运行脚本。成功后创建独立桌面快捷方式和自启动项；已有属于其他程序的同名快捷方式、自启动项或非空安装目录时会停止。安装中断后可重新运行安装包并选择相同位置，程序会校验已写入文件并尝试继续。
3. 自动网络规则无需输入或读取手机 IP，远程地址采用 Windows 本地 IPv4 子网，入站网卡限制为设置时已有的物理网卡。**匹配这些条件的其他设备也能访问三个小米互联程序；私人和公共网络均生效。** 这些条件分别由 Windows 判断，不承诺将每个远程子网与入站网卡逐一绑定。如果增加物理网卡或修改网卡名称，需要运行 `tools\configure-auto-firewall.cmd` 更新；可通过 `tools\remove-auto-firewall.cmd` 移除自动规则。原来的手机 IP 专属模式仍可通过 `tools\configure-firewall.cmd` 单独设置。
4. 打开轻剪面板并登录小米账号。登录成功后面板显示官方回调提供的账号名称。软件调用官方设备列表：发现一台手机时自动请求选择，多台时提示用户选择；选择请求不代表设备已经配对。不要向聊天发送账号密码、验证码或令牌。
5. 若官方组件提示修复后台服务，可按提示决定是否继续；此流程可能请求管理员授权。该服务可能是其他小米软件也会使用的共享组件。
6. 保持手机和电脑的设备互联条件满足后，分别测试电脑到手机、手机到电脑的文字和图片复制粘贴。面板的“服务已启动”表示服务状态，不代表每个方向均已验证。
7. 如失败，可先记录问题发生的步骤、提示文字，以及电脑的 Windows 版本。轻剪测试版日志在安装目录 `data\logs\status.log`；小米官方组件可能另写自己的日志。分享日志前请先查看其中是否含个人信息。

已有手机专属规则时，可运行安装目录的 `tools\test-auto-firewall.cmd`，在临时停用这些规则后测试自动规则；测试完成按回车恢复。如果测试窗口意外关闭，可运行 `tools\restore-manual-rules.cmd` 恢复测试前启用的原规则。

仓库另有独立的 `tools\diagnose-auto-firewall.cmd` 及配套脚本，可只读检查规则和网卡。该诊断工具会在内存中读取旧规则的地址用于比较，不显示地址，也不写入文件；它不属于自动设置功能，不随安装器安装。

## 卸载

在安装目录运行 `卸载轻剪.cmd`。确认后工具核对归属并请求管理员权限，移除属于此目录的服务、防火墙规则、快捷方式、自启动项和程序数据。其他位置的小米服务和共享缓存会保留；卸载新版本的流程仍需要在新电脑上实际验证。没有系统初始快照，不能保证共享数据完全恢复原样。

已安装的候选版内置卸载器存在路径处理错误，会导致卸载在停止服务前中断。修复后的安装包包含更正；已经安装的候选版可使用单独的卸载修复工具。修复已通过用户入口和服务权限的隔离模拟，仍需在目标电脑验证。

如果需要在非小米测试机上清理旧版后重新测试，可使用项目提供的一键清理工具。工具会核对安装路径和小米签名，只移除指向该安装目录的轻剪规则和服务、对应的快捷方式与自启动项；默认连同轻剪目录中的 `data` 一起删除。其他位置的小米服务和共享缓存不会删除。由于没有测试前的完整系统快照，不能保证将所有共享数据恢复到原始状态。

目标电脑首次清理时，小米服务的停止权限被拒绝。针对该服务的修复版在识别到已知限制时，会保存原权限、临时允许停止，之后立即恢复并验证；恢复失败会保留临时恢复记录并停止清理，再次运行时先尝试恢复。用户已在非小米电脑运行修复版，反馈清理完成，移除 6 条规则并注销 2 项本目录服务；随后一体安装版的文字、图片双向同步测试成功。

## 安全隔离

安装程序和运行入口发现当前电脑已经有现有轻剪进程或小米电脑管家目录时，会拒绝在该电脑启动实验版。项目中的现有小米电脑版源码和安装目录没有由此构建流程覆盖。

## 仓库与构建依赖

此目录是单仓库中的非小米电脑版本；根目录 `src/` 是小米电脑版。两版使用同一主分支，分别构建和验证。

第三方小米程序、账号数据、日志、下载包、构建产物和本机 `.tools` 不纳入 Git。当前实验构建脚本需要用户自行从小米官方取得已检查的 1.1.2.36 安装包、在 `research/private/continuity-archive-inspection/official` 准备离线组件，并在本地准备 Python `pefile`、.NET 6 运行时和 Windows C# 编译器；一个全新克隆不能直接构建，需先解决这些前置依赖。
