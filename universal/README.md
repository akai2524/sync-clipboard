# 轻剪同步通用测试版

这是给非小米 Windows 电脑进行可行性验证的独立实验构建，与这台小米电脑正在使用的轻剪分开。测试包不是已验证的正式版本。

## 当前验证范围

- 使用小米官方 Windows 通用版 1.1.2.36 安装包中签名有效的启动器和组件。自行编写的轻剪入口与安装程序不是小米官方文件；没有修改小米签名启动器。
- 已验证构建、安装包内容校验、小米签名宿主的自包含运行时启动自检和现有轻剪不受影响。自检不会登录小米账号、注册系统服务或启动互联组件。
- **用户已在非小米电脑反馈：文字和图片两个方向均无法同步。** 登录状态、设备发现、后台服务和失败原因仍待核实，不能把测试版视为可正常使用。具体测试电脑的 Windows 版本尚待核实；Windows 10 是额外实验目标。
- 安装包约 219 MB，因为目前保留了官方账号、互联、服务修复组件及独立运行时。文件体积不代表内存占用；内存需要在目标电脑实测。为确保首次验证可用，目前没有把所有组件缩到最少。

## 测试方法

1. 将 `轻剪同步通用测试版.exe` 复制到非小米电脑，运行安装程序。推荐选择 `D:\Apps` 作为父目录，安装程序会创建 `D:\Apps\LightClipUniversal`。如果目标电脑没有 D 盘，选择其他仅包含英文、数字及常用符号的目录。
2. 安装程序创建一个独立桌面快捷方式和本软件自启动项；已有同名快捷方式、自启动项或非空安装目录时会停止，避免覆盖。
3. 打开轻剪面板，点击“登录小米账号”，按官方登录界面提示操作。不要向聊天发送账号密码、验证码或令牌。右键系统托盘中的轻剪图标，选择“刷新并选择手机”；如果列表尚未更新，稍等后再试。面板显示的是组件返回的手机列表，不表示设备已经配对。
4. 若官方组件提示修复后台服务，可按提示决定是否继续；此流程可能请求管理员授权。该服务可能是其他小米软件也会使用的共享组件。
5. 保持手机和电脑的设备互联条件满足后，分别测试电脑到手机、手机到电脑的文字和图片复制粘贴。面板里的“服务已启动 · 待验证”仅表示初始化返回，不代表账号、配对或传输已成功。
6. 如失败，可先记录问题发生的步骤、提示文字，以及电脑的 Windows 版本。轻剪测试版日志在安装目录 `data\logs\status.log`；小米官方组件可能另写自己的日志。分享日志前请先查看其中是否含个人信息。

## 卸载测试版

在安装目录运行 `卸载测试版.cmd`。它请求轻剪退出，并仅在快捷方式和自启动项指向该测试版时移除它们；最后需要按提示手动删除安装目录。为了不影响其他软件，它不会自动卸载可能已安装的小米共享后台服务。

## 安全隔离

安装程序和运行入口发现当前电脑已经有现有轻剪进程或小米电脑管家目录时，会拒绝在该电脑启动实验版。项目中的现有小米电脑版源码和安装目录没有由此构建流程覆盖。

## 仓库与构建依赖

此目录是单仓库中的非小米电脑版本；根目录 `src/` 是小米电脑版。两版使用同一主分支，分别构建和验证。

第三方小米程序、账号数据、日志、下载包、构建产物和本机 `.tools` 不纳入 Git。当前实验构建脚本需要用户自行从小米官方取得已检查的 1.1.2.36 安装包、在 `research/private/continuity-archive-inspection/official` 准备离线组件，并在本地准备 Python `pefile`、.NET 6 运行时和 Windows C# 编译器；一个全新克隆不能直接构建，需先解决这些前置依赖。
