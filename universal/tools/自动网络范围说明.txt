轻剪自动网络设置（测试版）

此方案不获取或识别手机的具体 IP。它使用 Windows 的 LocalSubnet4 规则匹配本地 IPv4 子网，因此手机 IP 变化后不需要重新输入。

范围：Windows 本地 IPv4 子网中的设备可以通过现有物理网卡访问轻剪所用的三个小米互联程序的 TCP/UDP 入站端口；在公共和私人网络均生效。远程子网与入站网卡是分别判断的。它比只允许一个手机 IP 更宽。请确认接受此范围后使用。

双击 configure-auto-firewall.cmd，允许管理员授权；工具会尝试自动找到安装目录，找不到时才需要选择。原有手机专属规则保持不变。

配置完成后双击 test-auto-firewall.cmd，允许管理员授权。工具会暂时关闭本安装目录原有的手机专属规则，供你在电脑截图并到手机粘贴，完成后回到窗口按回车。工具会恢复测试前启用的手机专属规则，避免旧规则干扰自动方案的验证。若测试窗口意外关闭，请双击 restore-manual-rules.cmd 恢复。

双击 remove-auto-firewall.cmd 可以删除此安装目录建立的自动规则；它不会删除原有手机专属规则。如测试中断，应先运行恢复工具，再移除自动规则。

规则保存在 Windows 防火墙，不需要额外的后台程序。安装后增加新的物理网卡时需重新配置。用户在非小米电脑临时停用原规则后，确认电脑截图能通过自动规则粘贴到手机；重启后重复测试仍成功。新安装器和卸载流程尚未在目标电脑实测。
