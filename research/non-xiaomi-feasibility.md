# 非小米 Windows 电脑可行性调查

调查时间：2026-10-27。目标：手机端不安装额外应用，非小米 Windows 电脑只安装轻剪，通过小米账号实现文字、图片双向剪贴板同步。

## 已验证的线索

- [小米官方 Windows 互联说明](https://os1.hyperos.mi.com/continuity/abilities/ab0019)提供面向非小米电脑的 Windows 通用版，要求手机开启设备互联、电脑和手机处于同一局域网；页面没有明确列出图片剪贴板支持情况。
- [1.1.2.36 更新说明转载](https://sharess.cn/page/app/detail?id=vq7QV9SAPUItPJSkde2IllFAly9TTDbE_-Q9kIoUhq7axg%3D%3D)写明了电脑和手机双向复制粘贴文字等内容，但无法从该说明确认图片双向复制。
- 从官网链接下载的 1.1.2.36 安装包长度为 270822912 字节，MD5 为 `5E2236EEC98B71D61874D0162CF91FBA`，与 HTTP 标头一致，Windows 签名校验通过，签名主体为 Xiaomi Communications Co., Ltd.；未运行安装程序。
- 静态提取检查发现 `MiSmartShareClrWrapper.dll` 同时包含 `MiAccountBusinessCLRWrapper.HandleLogin`、`HandleGetLoginStatus` 和 `ClrClipboardSyncWrapper`；另有 `dist_clipboard.dll`、`micont_rtm.dll` 和 `micont_service.exe`。这证明安装包含相关接口，不证明直接调用可以登录、连接或传输。
- 当前轻剪预先初始化的 34 个包装器中，Windows 通用版只含 14 个同名类型。当前版本不能直接复制过来使用，需要按该版本重新适配；不能假定现有小米电脑管家服务或注册配置已经存在。
- 现有轻剪已经在小米电脑、原管家 5.4.0.620 和小米 14 上验证文字与图片双向同步，但依赖本机账号和互联服务，不能视为非小米电脑已验证。
- [UniClip](https://github.com/UniClipboard/UniClip) 是现成开源跨设备剪贴板方案，支持文字和图片，但需要移动端应用，不符合用户不安装手机软件的约束。

## 待验证

用户已反馈首个通用测试版在非小米电脑上，文字和图片两个方向均不能同步。账号登录、设备发现和底层服务状态待进一步核实；现有通用程序尚未实现完整设备发现与连接处理，可能与故障有关，尚不能认定为唯一原因。

1. 是否可在仅安装轻剪的条件下，使用官方许可允许的方式获取和使用必要组件，包括登录界面、设备身份、服务启动和配对。
2. 是否必须注册系统服务、使用管理员权限、安装特定运行时，及其对空闲内存和卸载的影响。
3. 在非小米 Windows 电脑和用户的小米手机上，分别实测电脑到手机、手机到电脑的文字和图片四个方向，并验证切换账号、断网重连和登录自启。
4. 组件版本升级及用户自行下载官方文件的来源校验。不得记录或让用户向聊天提供小米密码、令牌或验证码。

没有完成以上跨设备测试前，不能宣称已经有可分发、无需电脑管家的独立成品。
